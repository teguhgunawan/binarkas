# binarkas

Supaya uangmu makin tertata, hidupmu makin berbinar.

## Stack
- PHP 8.2+
- Bootstrap 5
- PostgreSQL
- Apache (XAMPP supported)

## Setup
1. Copy `.env.example` to `.env` and fill DB credentials.
2. Open `/binarkas/?page=setup` and run migrations.
3. Login with configured default admin credentials.

## Modules
- Dashboard
- Transactions
- Budgets
- Debts
- Reports
- Setup:
  - Manajemen User
  - Manajemen Akun (including saldo awal)
  - Manajemen Kategori
